# Drop grids here

Staging area for kakuro grids to hardcode (see
`spec/solvability_audits/kakuro_*` for why: the procedural generator is
structurally broken — 0% unique solutions — and "free" puzzle sites found so
far don't grant redistribution rights, so grids you personally provide are
the way forward).

Just drop whatever you have, one file per grid — screenshot, photo, text
copy/paste, a link in a `.txt` file, anything. No specific format needed,
I'll transcribe each one into the plugin's internal format (grid layout +
across/down clues + solution) by hand.

A couple of things that make transcription faster/safer if you can include
them, but don't hold up a drop for:
- the solution digits, if you have them (lets me verify the grid matches
  before wiring it in, instead of re-solving it myself)
- where it came from (site/book/your own puzzle), so we can keep track of
  what's actually safe to redistribute
